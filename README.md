# buddhist-divination-engine（佛教占卜引擎）

多流派佛教占卜法的本地桌面引擎（Electron）。数据全部来自古籍/经书原文整理，逐条核对、标注来源，不编造断语。

## 功能

| Tab | 内容 | 数据量 |
|---|---|---|
| 汉传灵签 | 观音灵签100签（天竺寺本）、六十甲子签63签（妈祖/天公系统）、地藏王殿灵签60签（荃湾本）、佛祖灵签51签（玄武山本） | 4 套灵签 |
| 观音32感应灵课 | 五钱占卜法 32 课，含原文 + 配图（从《观音灵课·五钱占卜法》逐页提取） | 32 课 + 64 图 |
| 地藏占察木轮 | 189 相全（依《占察善恶业报经》，含木轮构造/忏悔法/至心三品原文折叠区） | 189 相 |
| 藏传骰子卜 | 文殊占筮法 Mo 36 卦、观音明镜论 6 卦、吉祥天母骰子卜 16 卦（含前行仪轨/补遗附录折叠区） | 3 套藏法 |
| 菩萨占卜法 | 观音明镜论等（依索达吉译本，含总序折叠区） | — |

## 运行

```
npm install        # 仅开发需要；本引擎运行时零依赖（数据为本地 JSON）
npm start          # 或用 Electron 加载本目录
```

引擎不依赖任何外部网络，数据全在 `engine/data/*.json`，配图在 `engine/images/`。

## 打包（portable 单文件 exe）

打包工具统一放在 `D:\一个电脑软件\_共享工具\打包中心`（electron-builder 只装一份，全项目共享；Electron 发行包走全局缓存）：

```powershell
cd <本目录>
& D:\一个电脑软件\_共享工具\打包中心\node_modules\.bin\electron-builder.cmd --win portable
```

产物：`dist/佛教占卜引擎-portable.exe`（约 75 MB，单文件免安装）。
